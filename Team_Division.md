# Division of Work – 3 Members

| Member | Responsibility | Main files |
|---|---|---|
| Member 1 – AWT GUI and authentication | Login/registration screens, Student/Teacher role selection, dashboard UI and visual testing | `AuthFrame.java`, `DashboardFrame.java`, `Msg.java` |
| Member 2 – Database and teacher tools | SQLite schema/initialization, JDBC, password hashing and teacher question entry | `DB.java`, `PasswordUtil.java`, `AdminFrame.java` |
| Member 3 – Quiz engine | Question model, timer, answer selection, scoring, result saving, leaderboard, integration and testing | `Question.java`, `QuizFrame.java`, `Main.java` |

## Suggested 2-week schedule
- Days 1–2: Requirements, AWT screen sketches and database design.
- Days 3–5: SQLite initialization, JDBC, authentication and role selection.
- Days 6–8: Student/Teacher dashboards, category loading and quiz interface.
- Days 9–10: Timer, evaluation, results and leaderboard.
- Days 11–12: Teacher question management, integration and testing.
- Days 13–14: PPT, documentation, screenshots and rehearsal.

All members should understand the complete application flow and prepare for project viva questions.
